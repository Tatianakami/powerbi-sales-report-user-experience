## 📖 About the Project

This project presents the redesign of a financial dashboard developed in **Microsoft Power BI**, focusing on improving the **User Experience (UX)**, dashboard organization, readability, navigation, and visual hierarchy.

The objective was to transform the original report into a cleaner, more intuitive, and interactive dashboard by applying Business Intelligence and UX best practices.

---

# 🎯 Objectives

- Improve dashboard usability
- Apply UX principles
- Enhance visual hierarchy
- Improve navigation between report pages
- Organize information for faster decision making
- Increase readability
- Improve user interaction

---

# 🚀 Technologies

- Microsoft Power BI Desktop
- DAX
- Power Query
- Data Visualization

- Business Intelligence
